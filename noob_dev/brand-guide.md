# คู่มือแบรนด์ noob_dev (Brand Guide v1)

> แหล่งความจริงเดียวของทีม noob_dev Design — ทุกตำแหน่งต้องอ่านไฟล์นี้ก่อนเริ่มงาน
> ถ้าเจ้าของแบรนด์ส่งข้อมูลแบรนด์เดิมมา ให้อัปเดตไฟล์นี้ก่อนแล้วค่อยทำงานต่อ

## 1. บุคลิกแบรนด์
- **คำจำกัดความ:** นักพัฒนาสาย indie ที่ "ยังเป็นมือใหม่ตลอดไป" — อยากรู้ ลองของใหม่ ไม่เก๊ก แต่งานต้องเนี้ยบ
- **3 คำหลัก:** เป็นกันเอง · เนี้ยบ · ขี้เล่นนิดๆ
- **น้ำเสียง:** พูดภาษาคน สั้น ตรง มีมุกได้แต่ไม่ฝืน ใช้ไทยเป็นหลัก ทับศัพท์เทคนิคได้
- **ห้าม:** ภาษาองค์กรแข็งๆ, อีโมจิเกิน 1 ตัวต่อข้อความ, ศัพท์การตลาดเว่อร์ ("ปฏิวัติวงการ", "ที่สุดในโลก")

## 2. โลโก้ (Wordmark)
- ตัวอักษร `noob_dev` ฟอนต์ **IBM Plex Mono SemiBold** ตัวพิมพ์เล็กทั้งหมด
- เครื่องหมาย `_` เป็นสี Accent (เขียวนูบ) — สื่อถึงเคอร์เซอร์ terminal ที่รอพิมพ์ต่อ
- ไอคอนย่อ (avatar/favicon): `n_` บนพื้นสี่เหลี่ยมมุมมน สี Ink, `_` สี Accent
- พื้นที่ว่างรอบโลโก้ ≥ ความสูงตัว `n`
- **ห้าม:** ยืด/บีบ, ใส่เงา, เปลี่ยนสี `_` เป็นสีอื่น, ใช้ตัวพิมพ์ใหญ่

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512"><rect width="512" height="512" rx="112" fill="#0D1117"/><text x="256" y="318" text-anchor="middle" font-family="IBM Plex Mono, monospace" font-weight="600" font-size="220" fill="#E6EDF3">n<tspan fill="#A3E635">_</tspan></text></svg>
```

## 3. สี (Color Tokens)
ธีมหลักคือ **มืด (dark-first)** มีธีมสว่างรองรับ

| Token | Dark | Light | ใช้กับ |
|---|---|---|---|
| `--bg` | `#0D1117` | `#FAFAF7` | พื้นหลังหน้า |
| `--surface` | `#161B22` | `#FFFFFF` | การ์ด กล่อง |
| `--border` | `#2A313C` | `#E4E4DE` | เส้นขอบ |
| `--text` | `#E6EDF3` | `#14171C` | ตัวอักษรหลัก |
| `--muted` | `#8B949E` | `#5E6570` | ตัวอักษรรอง |
| `--accent` | `#A3E635` | `#4D7C0F` | **เขียวนูบ** — ปุ่มหลัก ลิงก์ `_` ในโลโก้ |
| `--accent-ink` | `#0D1117` | `#FFFFFF` | ตัวอักษรบนพื้น accent |
| `--pop` | `#F472B6` | `#DB2777` | สีเสริมขี้เล่น — ใช้ไม่เกิน 5% ของพื้นที่ (แท็ก ไฮไลต์) |
| `--warn` | `#FBBF24` | `#B45309` | เตือน |
| `--error` | `#F87171` | `#DC2626` | ผิดพลาด |

- สี Discord embed: `#A3E635` (ปกติ), `#F472B6` (ประกาศพิเศษ), `#F87171` (error)
- **กฎ:** accent 1 จุดเด่นต่อหน้าจอ, ข้อความต้องผ่านคอนทราสต์ WCAG AA (4.5:1 ตัวเล็ก, 3:1 ตัวใหญ่)

## 4. ตัวอักษร
| บทบาท | ฟอนต์ | หมายเหตุ |
|---|---|---|
| หัวข้อ + เนื้อหา (ไทย/อังกฤษ) | **IBM Plex Sans Thai** | Google Fonts, น้ำหนัก 400/500/700 |
| โลโก้ โค้ด ตัวเลข ป้ายเล็ก | **IBM Plex Mono** | น้ำหนัก 400/600 |

```html
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;600&family=IBM+Plex+Sans+Thai:wght@400;500;700&display=swap" rel="stylesheet">
```

- สเกลขนาด (px): 12 · 14 · 16 (เนื้อหา) · 20 · 24 · 32 · 48 · 64
- line-height: เนื้อหา 1.7 (ภาษาไทยต้องโปร่ง), หัวข้อ 1.3 (กันวรรณยุกต์ชนกันเมื่อหัวข้อขึ้นหลายบรรทัด)
- หัวข้อใช้ 700, letter-spacing -0.01em; ห้ามใช้ตัวเอียงกับภาษาไทย

## 5. ระยะห่างและรูปทรง
- สเกลระยะห่าง (px): 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 — **ห้ามใช้ค่านอกสเกล**
- ความกว้างเนื้อหาสูงสุด 1120px, ขอบข้างมือถือ 16px
- มุมมน: 6 (ปุ่มเล็ก/แท็ก) · 12 (การ์ด) · 20 (กล่องใหญ่) · 999 (pill)
- เงา: ธีมมืดใช้เส้นขอบแทนเงา; ธีมสว่างใช้ `0 1px 2px rgb(0 0 0 / .06), 0 4px 16px rgb(0 0 0 / .06)`
- โมชัน: 150–250ms ease-out, เคารพ `prefers-reduced-motion`

## 6. ส่วนประกอบพื้นฐาน
- **ปุ่มหลัก:** พื้น `--accent` ตัวอักษร `--accent-ink`, สูง 44px, padding 0 20px, มุม 6
- **ปุ่มรอง:** พื้นโปร่ง ขอบ `--border` ตัวอักษร `--text`
- **การ์ด:** พื้น `--surface` ขอบ 1px `--border` มุม 12 padding 24
- **แท็ก:** Plex Mono 12px ตัวพิมพ์เล็ก พื้น `--surface` มุม 999
- **ลายเซ็นแบรนด์:** ป้าย/หัวข้อเล็กขึ้นต้นด้วย `>` หรือ `//` แบบ terminal (ใช้พอประมาณ)

## 7. ขนาดงานกราฟิก
| งาน | ขนาด (px) |
|---|---|
| Discord server icon / bot avatar | 512 × 512 |
| Discord server banner | 960 × 540 |
| Discord invite splash | 1920 × 1080 |
| Discord embed image | 1200 × 600 (ไม่เกิน 8MB) |
| GitHub social preview | 1280 × 640 |
| README banner | 1280 × 320 |
| ภาพหน้าจอพอร์ตโฟลิโอ | 1600 × 1000 |

กราฟิกทุกชิ้น: พื้น `--bg` มืด, wordmark มุมใดมุมหนึ่ง, เว้นขอบปลอดภัย 48px

## 8. Checklist ตรวจคุณภาพ (ผู้ตรวจใช้)
1. สี ฟอนต์ ระยะห่าง มุมมน ตรง token ทั้งหมด (ไม่มีค่ามั่ว)
2. คอนทราสต์ผ่าน WCAG AA
3. ภาษาไทยไม่โดนตัด: เนื้อหา line-height ≥ 1.6, หัวข้อ = 1.3
4. มือถือ 375px ไม่มี scroll แนวนอน, ปุ่ม/ลิงก์แตะได้ ≥ 44px
5. accent มีจุดเด่นเดียวต่อหน้าจอ, `--pop` ไม่เกิน 5%
6. ใช้คีย์บอร์ดได้ มี focus ring (`2px solid var(--accent)` offset 2px), รูปมี alt
7. น้ำเสียงข้อความตรงหมวดที่ 1
